Créer la base en mode assisté (phpMyAdmin)

Annexe 3ème

En 3ème, la base et ses tables se créent avec l'interface graphique : aucune instruction CREATE, ALTER ou DROP n'est écrite à la main.

  1. Démarrer XAMPP

    Lancer Apache et MySQL, puis ouvrir localhost/phpmyadmin.

  2. Créer la base

    Onglet Bases de données : saisir bibliotheque, interclassement utf8mb4_general_ci.

  3. Créer chaque table

    Nom, nombre de colonnes, puis pour chaque champ : nom, type, taille, Null ou non, index PRIMARY.

  4. Relier les tables

    Onglet Structure → Vue relationnelle : choisir la table et le champ référencés (moteur InnoDB).

  5. Saisir des données

    Onglet Insérer, puis vérifier dans Parcourir.

Interroger une table en SQL

Annexe 3ème
SQL
-- Sélection, condition, tri
SELECT titre, annee FROM Livre
WHERE annee >= 2000
ORDER BY annee DESC;

-- Sans doublons
SELECT DISTINCT nationalite FROM Auteur;

-- Opérateurs
SELECT * FROM Livre WHERE annee BETWEEN 1990 AND 2010;
SELECT * FROM Livre WHERE titre LIKE 'Le%';
SELECT * FROM Eleve WHERE classe IN ('3SI1', '3SI2');
SELECT * FROM Livre WHERE idAuteur IS NULL;

-- Mise à jour des données
INSERT INTO Eleve (idEleve, nom, prenom, classe)
VALUES (25, 'Ben Salah', 'Rim', '3SI1');

UPDATE Eleve SET classe = '3SI2' WHERE idEleve = 25;

DELETE FROM Eleve WHERE idEleve = 25;
!

En 3ème : une seule table par requête. Jointures, fonctions d'agrégation, GROUP BY et sous-requêtes sont réservés à la 4ème.

À retenir

  • Clé primaire soulignée, clé étrangère suivie de #.
  • Relation ∞:∞ = table intermédiaire.
  • Création de la base et des tables : mode assisté, puis commandes SQL (CREATE, ALTER, DROP — programme 2026).
  • Requêtes SQL sur une seule table.
