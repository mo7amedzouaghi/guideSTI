Script externe obligatoire

Annexe 4ème

En 4ème, tout le code JavaScript est dans un fichier .js relié par <script src>. Aucun script interne dans la page.

✗ Incorrect
HTML
<script>
  function verifier() { … }
</script>
✔ Conforme
HTML
<script src="js/controle.js"></script>

Groupe de boutons radio : getElementsByName

Annexe 4ème
JSjs/controle.js
function choixFiliere() {
  let options = document.getElementsByName("filiere");
  let choix = "";
  for (let i = 0; i < options.length; i++) {
    if (options[i].checked) {
      choix = options[i].value;
    }
  }
  if (choix == "") {
    alert("Choisissez une filière");
    return;
  }
  document.getElementById("res").innerHTML = "Filière : " + choix;
}

Liste déroulante : selectedIndex

Annexe 4ème
JSjs/controle.js
function verifierGouv() {
  let liste = document.getElementById("gouv");
  if (liste.selectedIndex == 0) {
    alert("Choisissez un gouvernorat");
    return;
  }
  document.getElementById("res").innerHTML =
    "Choix : " + liste.value;
}
localhost/page.html
i

L'option 0 (« -- Choisir -- ») sert de message : selectedIndex == 0 signifie qu'aucun vrai choix n'a été fait.

Modifier attributs, styles et médias

Annexe 4ème

Syntaxe générale : element.attribut = valeur, element.style.propriété = valeur, element.méthode().

JSjs/script.js
let v = document.getElementById("video");
let img = document.getElementById("img");
let ok = document.getElementById("accord");
let btn = document.getElementById("envoyer");

ok.checked = true;            // attribut
btn.disabled = false;
document.getElementById("cin").readOnly = true;
img.src = "images/kairouan.jpg";
v.muted = true;

img.style.width = "200px";    // style
img.style.border = "3px solid gold";

v.play();                     // méthodes média
v.pause();
localhost/page.html
Cochez la case : le bouton s'active et le style du cadre change.
Propriété JSEffet
valueValeur d'un champ
checkedCase cochée ou non
disabledÉlément désactivé
readOnlyChamp en lecture seule (attention à la majuscule O)
srcSource d'une image ou d'un média
mutedSon coupé
style.propriétéModifie une propriété CSS (color, background, border, font, width, height)
play() / pause()Lecture / pause d'un média

Contrôler avant l'envoi vers PHP

Annexe 4ème

Quand le formulaire part vers une page PHP, le contrôle se branche sur onsubmit de la balise form : la fonction renvoie false pour bloquer l'envoi, true pour l'autoriser.

HTMLinscription.html
<form action="inscription.php" method="post" onsubmit="return verifier()">
  <input type="text" id="nom" name="nom">
  <input type="submit" value="S'inscrire">
</form>
JSjs/controle.js
function verifier() {
  let nom = document.getElementById("nom").value;
  if (nom.length < 3) {
    alert("Nom trop court");
    return false;
  }
  return true;
}

À retenir

  • Script toujours externe en 4ème.
  • Groupe radio : getElementsByName + boucle sur checked.
  • Liste déroulante : tester selectedIndex.
  • onsubmit="return verifier()" pour un envoi vers PHP.

Méthodes et fonctions

Méthode / fonctionDéfinition

element.attribut = valeurModifie un attribut (value, checked, disabled, readOnly, src, muted)
element.style.propriété = valeurModifie une propriété CSS de l'élément
element.play() / pause()Lance / suspend un média
