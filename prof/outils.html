Mettre en route un projet PHP

Les étapes à suivre à chaque séance de 4ème.

  1. Lancer XAMPP Control Panel

    Cliquer sur Start devant Apache et MySQL : les deux lignes passent au vert.

  2. Placer le projet dans htdocs

    Dossier C:\xampp\htdocs\bibliotheque\ contenant les pages et connexion.php.

  3. Créer ou importer la base

    Dans phpMyAdmin : nouvelle base, ou onglet Importer pour un fichier .sql fourni.

  4. Ouvrir par le serveur

    Saisir localhost/bibliotheque/ dans le navigateur. Un double-clic sur un fichier .php affiche le code au lieu de l'exécuter.

!

Apache ne démarre pas ? Un autre logiciel occupe souvent le port 80 (Skype, IIS). Fermez-le ou changez le port d'Apache dans la configuration de XAMPP.

Glossaire

Les mots du programme, définis simplement, pour l'enseignant comme pour l'élève.

Annexe
Document officiel qui liste, pour chaque niveau, les balises, propriétés, méthodes et instructions au programme.
Attribut
Information ajoutée dans une balise HTML : src, href, name…
Balise
Élément de structure HTML délimité par des chevrons : <p>…</p>.
Balise sémantique
Balise qui indique le rôle d'une zone : header, nav, main, footer…
Clé étrangère
Champ qui fait référence à la clé primaire d'une autre table ; notée avec #.
Clé primaire
Champ (ou groupe de champs) qui identifie chaque enregistrement de façon unique ; soulignée.
Concaténation
Mise bout à bout de chaînes : + en JavaScript, . en PHP.
CSS externe
Feuille de style dans un fichier .css relié par <link> ; partagée par toutes les pages.
DOM
Représentation de la page que JavaScript manipule (getElementById, innerHTML).
Enregistrement
Une ligne d'une table : toutes les valeurs décrivant un même objet.
Événement
Action qui déclenche du code : clic, saisie, survol, chargement de la page.
Jointure
Mise en relation de plusieurs tables par l'égalité clé étrangère = clé primaire, écrite dans WHERE.
LDD / LMD
Langage de définition des données (CREATE, ALTER, DROP) / de manipulation (SELECT, INSERT, UPDATE, DELETE).
Mode assisté
Création de la base et des tables par l'interface de phpMyAdmin, sans écrire de SQL (3ème).
Modèle de boîte
Découpage d'un élément en contenu, padding, bordure et margin.
mysqli
Ensemble de fonctions PHP procédurales pour dialoguer avec MySQL (seule méthode au programme).
Pseudo-classe
Sélecteur d'un état : :hover, :focus, a:visited…
Requête
Instruction SQL adressée à la base pour lire ou modifier des données.
SGBDR
Système de gestion de bases de données relationnelles, par exemple MySQL.
Sous-requête
Requête SELECT placée dans une autre ; en 4ème, uniquement non corrélée.
Superglobale
Tableau PHP disponible partout : $_GET (paramètres d'URL), $_POST (formulaire).
Transition
Passage progressif d'une valeur CSS à une autre lors d'un changement d'état.
Validation W3C
Contrôle automatique de la conformité d'une page HTML aux normes du Web.
