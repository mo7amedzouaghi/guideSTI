Deux façons d'écrire le CSS en 2ème

Annexe 2ème

En 2ème année, le CSS s'écrit en ligne (attribut style, pour un seul élément) ou en interne (balise <style> dans le <head>, pour toute la page). La syntaxe est toujours : sélecteur { propriété: valeur; }.

HTML
<head>
  <meta charset="UTF-8">
  <title>Club</title>
  <style>
    h1 {
      color: navy;
      text-align: center;
    }
  </style>
</head>
<body>
  <h1>Club informatique</h1>
  <p style="color: green;">Inscriptions ouvertes</p>
</body>
localhost/page.html
i

Sélecteurs utilisés en 2ème : le nom de l'élément (h1, p, table…). Les sélecteurs #id et .classe arrivent en 3ème.

Mettre en forme le texte

Annexe 2ème
CSS
<style>
  h2 {
    font-family: Georgia, serif;
    font-size: 26px;
    color: darkred;
  }
  p {
    font-weight: bold;
    font-style: italic;
    text-align: justify;
  }
</style>
localhost/page.html
★

La propriété abrégée font regroupe style, graisse, taille et police : font: italic bold 18px Arial;

Bordures

Annexe 2ème
CSS
<style>
  table {
    border-width: 2px;
    border-style: solid;
    border-color: navy;
  }
  td {
    border: 1px dashed gray;
  }
</style>
localhost/page.html

Arrière-plans

Annexe 2ème
CSS
<style>
  body {
    background-color: lightyellow;
  }
  h1 {
    background-image: url("motif.png");
    background-repeat: repeat-x;
  }
</style>
localhost/page.html
L'image de fond est remplacée ici par une couleur.

À retenir

  • CSS en ligne : attribut style ; CSS interne : <style> dans le head.
  • Syntaxe : sélecteur { propriété: valeur; }, chaque déclaration se termine par ;.
  • Gras et italique se font en CSS : font-weight, font-style.
  • Pas de fichier .css externe en 2ème année.
