Relier une feuille de style et un script

Annexe 3ème

À partir de la 3ème, le CSS et le JavaScript vivent dans des fichiers séparés, reliés dans le <head>. Une même feuille de style sert alors à toutes les pages du site.

HTMLindex.html
<head>
  <meta charset="UTF-8">
  <title>Découvrir la Tunisie</title>
  <link rel="stylesheet" type="text/css" href="css/style.css">
  <script type="text/javascript" src="js/controle.js"></script>
</head>
BaliseAttributs (annexe)Rôle
<link>href, rel, typeRelie une ressource externe (feuille de style)
<script>src, typeRelie (ou contient) un script JavaScript
<style>type, mediaFeuille de style interne

Les balises de structuration sémantique

Annexe 3ème

Les balises sémantiques remplacent les <div> anonymes par des zones qui ont un sens. La page devient lisible comme un plan, par l'élève comme par les moteurs de recherche.

HTML
<body>
  <header>Découvrir la Tunisie</header>
  <nav>Accueil | Régions | Contact</nav>
  <main>
    <section>
      <article>Carthage</article>
      <article>Dougga</article>
    </section>
    <aside>Le saviez-vous ?</aside>
  </main>
  <footer>
    <address>Lycée Oued Ellil</address>
  </footer>
</body>
localhost/page.html
Bordures ajoutées uniquement pour visualiser les zones.
BaliseContenu attendu
<header>En-tête : logo, titre du site
<nav>Menu de navigation
<main>Contenu principal (un seul par page)
<section>Regroupement thématique
<article>Contenu autonome (fiche, actualité)
<aside>Contenu annexe, encadré
<footer>Pied de page
<address>Coordonnées de contact
<cite>Titre d'une œuvre citée

Conteneurs, iframe, figure et details

Annexe 3ème

<div> (bloc) et <span> (en ligne) sont des conteneurs neutres, utiles pour appliquer un style. <iframe> affiche une autre page à l'intérieur de la page ; nommé par name, il peut servir de cible à un lien. <figure> associe une illustration à sa légende <figcaption>, et <details> / <summary> créent un bloc dépliable.

HTML
<a href="carthage.html" target="cadre">Carthage</a>
<iframe src="accueil.html" name="cadre"
        width="300" height="80"></iframe>

<figure>
  <img src="dougga.jpg" alt="Théâtre de Dougga">
  <figcaption>Le théâtre romain de Dougga</figcaption>
</figure>

<details>
  <summary>Horaires de visite</summary>
  Tous les jours de 8h à 17h.
</details>
localhost/page.html
Cliquez sur « Horaires de visite » pour déplier.

Formulaires : nouveaux types et attributs

Annexe 3ème

La 3ème enrichit les formulaires de types spécialisés et d'attributs de contrôle. Le bouton qui déclenche un contrôle JavaScript est un <input type="button">.

HTML
<form>
  <input type="email" placeholder="adresse@mail.tn" required>
  <input type="tel" placeholder="8 chiffres">
  <input type="password" placeholder="Mot de passe">
  <input type="date" min="2026-09-15">
  <input type="time">
  Niveau : <input type="range" min="1" max="10" value="5">
  <input type="text" value="Oued Ellil" readonly>
  <input type="button" value="Valider" onclick="verifier()">
</form>

passwordname, value, placeholder, readonly, required, disabled
number, rangename, value, readonly, required, disabled, min, max
date, timename, value, required, disabled, min, max
checkbox, radioname, value, required, disabled, checked
button, reset, submitname, value, disabled

Événements HTML

Annexe 3ème

Un événement relie une action de l'utilisateur à une fonction JavaScript, directement dans la balise. En 3ème, on n'utilise pas addEventListener.

ÉvénementSe déclenche quand…Exemple
onclickon clique sur l'élément<input type="button" onclick="calculer()">
oninputla valeur change à chaque modification<input type="range" oninput="afficher()">
onchangela valeur change et le champ est quitté<input type="date" onchange="age()">
onfocusle champ reçoit le focus<input onfocus="aide()">
onblurle champ perd le focus<input onblur="verifierNom()">
onloadla page a fini de charger<body onload="init()">

À retenir

  • CSS et JS sont dans des fichiers externes reliés par link et script.
  • Balises sémantiques : header, nav, main, section, article, aside, footer.
  • Un iframe nommé (name) devient la cible d'un lien (target).
  • Bouton de contrôle : <input type="button" onclick="…">, jamais <button>.

Balises de la séquence

BaliseAttributs (annexe)DéfinitionUtilité
<link>href, rel, typeLien vers une ressource externe.Relier la feuille de style .css à la page.
<script>src, typeScript JavaScript (interne ou externe).Relier le fichier .js qui rend la page interactive.
<header>—En-tête de la page ou d'une section.Contenir le logo, le titre du site, le slogan.
<nav>—Zone de navigation.Regrouper les liens du menu principal.
<main>—Contenu principal (un seul par page).Délimiter le contenu propre à la page, hors en-tête et pied.
<footer>—Pied de la page ou d'une section.Afficher les coordonnées, l'auteur, les mentions.
<section>—Regroupement thématique.Découper le contenu en grandes parties, chacune avec son titre.
<article>—Contenu autonome.Présenter une fiche, une actualité ou un produit compréhensible seul.
<aside>—Contenu complémentaire.Placer un encadré, une info « Le saviez-vous ? », des liens annexes.
<div>—Conteneur neutre de type bloc.Regrouper des éléments pour leur appliquer un style quand aucune balise sémantique ne convient.
<span>—Conteneur neutre en ligne.Mettre en forme une partie d'un texte (avec une classe).
<iframe>src, nameCadre affichant une autre page.Intégrer une page dans la page ; nommé, il sert de cible (target) aux liens.
<figure>—Illustration autonome.Associer une image (ou un schéma) à sa légende.
<figcaption>—Légende d'une figure.Décrire l'image contenue dans figure.
<details>openBloc dépliable.Masquer un contenu secondaire que le visiteur affiche s'il le souhaite.
<summary>—Titre cliquable d'un details.Indiquer ce que contient le bloc dépliable.
<address>—Coordonnées de contact.Donner l'adresse, le téléphone ou l'e-mail de l'auteur ou de l'établissement.
<cite>—Titre d'une œuvre.Citer le titre d'un livre, d'un film ou d'un article.
