Le modèle de boîte

Annexe 3ème

Chaque élément est une boîte : le contenu (width, height), la marge intérieure (padding), la bordure, puis la marge extérieure (margin).

CSS
.carte {
  width: 220px;
  padding: 15px;
  border: 3px solid #1D4ED8;
  margin: 20px;
  border-radius: 10px;
  box-shadow: 4px 4px 8px gray;
}

display, float et position

Annexe 3ème

La mise en page de 3ème repose sur float (blocs côte à côte) et position. Pour une page pleine hauteur : html, body { height: 100%; } puis des hauteurs en % sur les enfants.

CSS
nav {
  float: left;
  width: 25%;
}
section {
  float: right;
  width: 70%;
}
footer {
  clear: both;
}
.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
localhost/page.html
Valeur de positionComportement
staticPlacement normal (par défaut)
relativeDécalé par rapport à sa place normale (top, left…)
absolutePlacé par rapport au premier parent positionné
fixedFixé à la fenêtre, ne défile pas
stickyNormal puis collé au bord pendant le défilement
!

clear ne figure pas dans l'annexe actuelle ; il reste indispensable pour arrêter un flottement. Les membres du comité de réforme proposent de l'y ajouter.

Débordement et transparence

Annexe 3ème
CSS
.actualites {
  height: 70px;
  overflow: scroll;
}
.filigrane {
  opacity: 0.4;
}
localhost/page.html

À retenir

  • Taille totale d'une boîte = width + padding + border + margin.
  • float place les blocs côte à côte ; le pied de page arrête le flottement.
  • top, left… n'agissent que sur un élément positionné.
  • Flexbox et Grid ne sont pas au programme.
