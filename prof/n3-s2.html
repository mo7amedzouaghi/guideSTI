Sélecteurs de base

Annexe 3ème
CSScss/style.css
/* style.css */
p { color: #333; }              /* élément   */
#titre { color: navy; }         /* id        */
.important { color: crimson; }  /* classe    */
h2, h3 { font-family: Arial; }  /* groupe    */
* { margin: 0px; }              /* universel */
localhost/page.html
i

Un id est unique dans la page ; une class peut être partagée par plusieurs éléments.

À retenir

  • Sélecteurs de 3ème : élément, #id, .classe, groupe, universel.
  • Une seule feuille de style externe pour tout le site.
  • Unités : px et % uniquement (pas de em, rem, vh, vw).
