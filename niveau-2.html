01

Structure d'une page HTML5

La charpente de toute page web : le squelette obligatoire, les titres, les paragraphes et la validation W3C.

Le squelette obligatoire

Annexe 2ème

Toute page commence par le même squelette. L'élève doit savoir l'écrire de mémoire et expliquer le rôle de chaque ligne : le <head> décrit la page (encodage, titre de l'onglet), le <body> contient ce que le visiteur voit.

HTMLindex.html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Mon lycée</title>
</head>
<body>
  <h1>Lycée Oued Ellil</h1>
  <p>Bienvenue sur le site de notre lycée.</p>
</body>
</html>
localhost/index.html
Le titre « Mon lycée » s'affiche dans l'onglet, pas dans la page.
ÉlémentRôle
<!DOCTYPE html>Déclare un document HTML5. Toujours en première ligne.
<html lang="fr">Élément racine ; l'attribut lang indique la langue de la page.
<meta charset="UTF-8">Encodage des caractères : indispensable pour les accents (é, à, ç).
<title>Titre affiché dans l'onglet du navigateur et dans les favoris.
<body>Contenu visible de la page.
✎

Faites d'abord retirer la ligne meta charset pour montrer l'effet sur les accents : l'élève retient mieux une erreur qu'il a provoquée lui-même.

Titres, paragraphes et séparations

Annexe 2ème

Les titres <h1> à <h6> hiérarchisent le contenu (un seul h1 par page). Le paragraphe <p> regroupe un bloc de texte, <br> force un retour à la ligne et <hr> trace une ligne de séparation thématique.

HTML
<h1>Club informatique</h1>
<h2>Nos activités</h2>
<p>Programmation, robotique<br>
et création de sites web.</p>
<hr>
<h2>Inscriptions</h2>
<p>Ouvertes jusqu'au 15 novembre.</p>
localhost/page.html
!

La mise en forme (gras, italique, couleur) ne se fait jamais avec des balises HTML comme <b>, <i> ou <strong> : elle passe par le CSS (font-weight, font-style). HTML = structure, CSS = présentation.

Valider sa page avec le W3C

Annexe 2ème

Une page « qui s'affiche » n'est pas forcément correcte. Le validateur officiel validator.w3.org signale les erreurs (balise non fermée, attribut obligatoire manquant) et les avertissements.

  1. Copier le code

    Sélectionner tout le code de la page dans l'éditeur.

  2. Coller dans « Validate by Direct Input »

    Puis cliquer sur Check.

  3. Corriger de haut en bas

    Une seule erreur (une balise non fermée) peut en provoquer plusieurs autres : on corrige la première puis on revalide.

✗ Incorrect
HTML
<img src="lycee.jpg">
<p>Notre lycée
✔ Conforme
HTML
<img src="lycee.jpg" alt="Façade du lycée">
<p>Notre lycée</p>

Erreurs signalées par le validateur : attribut alt manquant sur l'image et paragraphe non fermé.

À retenir

  • Le squelette HTML5 est toujours le même : DOCTYPE, html, head, body.
  • meta charset="UTF-8" garantit l'affichage des accents.
  • Un seul h1 par page, puis h2, h3… dans l'ordre.
  • HTML décrit la structure, jamais la mise en forme.
  • Une page est terminée quand elle passe le validateur W3C sans erreur.

Balises de la séquence

BaliseAttributs (annexe)DéfinitionUtilité
<html>langÉlément racine qui contient toute la page.Indiquer la langue du document (fr) aux navigateurs et aux lecteurs d'écran.
<head>—En-tête du document, non affiché dans la page.Regrouper les informations sur la page : encodage, titre, styles.
<meta>charset, name, contentMétadonnée décrivant la page.Déclarer l'encodage UTF-8 pour afficher correctement les accents.
<title>—Titre du document.Afficher un nom dans l'onglet du navigateur et dans les favoris.
<body>—Corps du document.Contenir tout ce que le visiteur voit.
<h1> à <h6>—Titres de niveau 1 (le plus important) à 6.Hiérarchiser le contenu comme le plan d'un document.
<p>—Paragraphe de texte.Regrouper des phrases en un bloc séparé des autres.
<br>—Retour à la ligne (balise orpheline).Passer à la ligne à l'intérieur d'un même paragraphe (adresse, poème).
<hr>—Ligne horizontale de séparation.Marquer un changement de thème entre deux parties.

02

Listes et tableaux

Organiser l'information : listes à puces, listes numérotées et tableaux de données.

Listes à puces et listes ordonnées

Annexe 2ème

<ul> crée une liste à puces (l'ordre n'a pas d'importance), <ol> une liste numérotée (l'ordre compte). Chaque élément est dans un <li>. La liste ordonnée accepte trois attributs de l'annexe : type, start et reversed.

HTML
<h3>Matériel du labo</h3>
<ul>
  <li>Ordinateurs</li>
  <li>Imprimante</li>
</ul>

<h3>Classement du tournoi</h3>
<ol type="I" start="1">
  <li>3ème Info 1</li>
  <li>3ème Info 2</li>
</ol>

<h3>Compte à rebours</h3>
<ol reversed>
  <li>Prêts</li>
  <li>Partez</li>
</ol>
localhost/page.html
Attribut de <ol>ValeursEffet
type1, A, a, I, iStyle de numérotation
startun entierNuméro du premier élément
reversedsans valeurNumérotation décroissante

Tableaux de données

Annexe 2ème

Un tableau se construit ligne par ligne : <tr> (ligne), puis les cellules <th> (en-tête) ou <td> (donnée). <caption> donne un titre au tableau, <thead>, <tbody> et <tfoot> en délimitent les parties.

HTML
<table border="1">
  <caption>Emploi du temps — lundi</caption>
  <thead>
    <tr><th>Heure</th><th>Matière</th></tr>
  </thead>
  <tbody>
    <tr><td>8h</td><td>Informatique</td></tr>
    <tr><td>10h</td><td>Mathématiques</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Total</td><td>2 séances</td></tr>
  </tfoot>
</table>
localhost/page.html
★

Faites dessiner le tableau sur papier avant de le coder : l'élève compte les lignes, et chaque ligne devient un <tr>.

À retenir

  • ul : ordre sans importance ; ol : ordre significatif.
  • Chaque élément de liste est dans un li.
  • Un tableau se lit ligne par ligne : tr puis th / td.
  • caption se place juste après <table>.

Balises de la séquence

BaliseAttributs (annexe)DéfinitionUtilité
<ul>—Liste non ordonnée (à puces).Énumérer des éléments dont l'ordre n'a pas d'importance.
<ol>type, start, reversedListe ordonnée (numérotée).Énumérer des étapes ou un classement où l'ordre compte.
<li>—Élément d'une liste.Contenir chaque item d'un ul ou d'un ol.
<table>—Tableau.Présenter des données en lignes et en colonnes.
<caption>—Titre du tableau.Annoncer le contenu du tableau ; se place juste après .
<thead>—En-tête du tableau.Regrouper la ou les lignes de titres des colonnes.
<tbody>—Corps du tableau.Regrouper les lignes de données.
<tfoot>—Pied du tableau.Regrouper les lignes de total ou de synthèse.
<tr>—Ligne du tableau.Contenir les cellules d'une même ligne.
<th>—Cellule d'en-tête.Donner le titre d'une colonne ou d'une ligne (gras et centré par défaut).
<td>—Cellule de donnée.Contenir une valeur du tableau.

03

Liens et multimédia

Naviguer entre les pages et intégrer images, sons et vidéos.

Les liens hypertextes

Annexe 2ème

La balise <a> crée un lien. href indique la destination, target la fenêtre d'ouverture.

HTML
<a href="contact.html">Nous contacter</a>
<a href="https://www.education.tn" target="_blank">Site du ministère</a>
Valeur de targetEffet
_selfMême onglet (par défaut)
_blankNouvel onglet
_parentCadre parent
_topFenêtre entière
i

Chemins relatifs : contact.html (même dossier), pages/contact.html (sous-dossier), ../index.html (dossier parent). C'est la première source d'erreur en TP.

Images, audio et vidéo

Annexe 2ème

<img> exige src (le fichier) et alt (le texte de remplacement). <audio> et <video> utilisent src et controls pour afficher les boutons de lecture.

HTML
<img src="images/lycee.jpg" alt="Façade du lycée">

<audio src="sons/hymne.mp3" controls></audio>

<video src="videos/visite.mp4" controls></video>
!

Sans controls, le lecteur est invisible et l'élève croit que « la vidéo ne marche pas ».

À retenir

  • href = destination, target = où ouvrir.
  • alt est obligatoire sur chaque image (validation W3C).
  • controls affiche les commandes audio/vidéo.
  • Noms de fichiers sans espace ni accent : photo_classe.jpg.

Balises de la séquence

BaliseAttributs (annexe)DéfinitionUtilité
<a>href, targetLien hypertexte.Naviguer vers une autre page, un site ou un fichier.
<img>src, altImage (balise orpheline).Afficher une photo ou une illustration ; alt la décrit si elle ne s'affiche pas.
<audio>src, controlsLecteur de son.Intégrer un fichier audio avec ses boutons de lecture.
<video>src, controlsLecteur vidéo.Intégrer une vidéo avec ses commandes.

04

Formulaires

Recueillir des informations : zones de saisie, choix multiples, listes et boutons.

La balise form et les champs de base

Annexe 2ème

Le formulaire regroupe les champs. <label for="…"> relie un texte à un champ via son id : cliquer sur le texte active le champ. <fieldset> et <legend> regroupent visuellement des champs liés.

HTMLinscription.html
<form action="inscription.php" method="post">
  <fieldset>
    <legend>Inscription au club</legend>
    <label for="nom">Nom :</label>
    <input type="text" id="nom" name="nom"><br>

    <label for="age">Âge :</label>
    <input type="number" id="age" name="age"><br>

    Classe :
    <input type="radio" name="classe" value="2A"> 2A
    <input type="radio" name="classe" value="2B"> 2B<br>

    <input type="checkbox" name="photo" value="oui">
    J'accepte d'être photographié(e)<br>

    <input type="submit" value="Envoyer">
    <input type="reset" value="Effacer">
  </fieldset>
</form>
localhost/inscription.html
!

Les boutons radio d'un même groupe portent le même name : c'est ce qui rend le choix exclusif.

Listes déroulantes et zones de texte

Annexe 2ème

<select> propose une liste de <option> ; selected présélectionne une option et multiple autorise plusieurs choix. <textarea> accepte un texte sur plusieurs lignes.

HTML
<label for="gouv">Gouvernorat :</label>
<select id="gouv" name="gouv">
  <option value="">-- Choisir --</option>
  <option value="Manouba" selected>Manouba</option>
  <option value="Tunis">Tunis</option>
</select>
<br>
<label for="msg">Message :</label><br>
<textarea id="msg" name="msg" rows="3" cols="30"
  maxlength="200" placeholder="Votre message"></textarea>
localhost/page.html

À retenir

  • method vaut get ou post ; action désigne la page de traitement.
  • name identifie la donnée envoyée, id sert au label.
  • Radio : même name pour un choix unique.
  • En 2ème : text, number, radio, checkbox, submit, reset uniquement.

Balises et types de la séquence

BaliseAttributs (annexe)DéfinitionUtilité
<form>action, method, targetFormulaire.Regrouper des champs et envoyer leurs valeurs à une page de traitement.
<fieldset>—Groupe de champs.Encadrer des champs liés (identité, coordonnées).
<legend>—Titre d'un fieldset.Nommer le groupe de champs.
<label>forÉtiquette d'un champ.Décrire le champ ; un clic sur l'étiquette active le champ dont l'id est for.
<input>type, name, valueChamp de saisie (text, number, radio, checkbox, submit, reset).Recueillir une donnée ou déclencher l'envoi / la remise à zéro.
<select>name, required, disabled, multipleListe déroulante.Proposer un choix parmi plusieurs options sans encombrer la page.
<option>value, selectedChoix d'une liste.Définir chaque valeur proposée par le select.
<textarea>name, rows, cols, maxlength, placeholderZone de texte multiligne.Saisir un texte long (message, commentaire).

CSS en ligne et interne

Mettre en forme sans fichier externe : texte, bordures et arrière-plans.

Deux façons d'écrire le CSS en 2ème

Annexe 2ème

En 2ème année, le CSS s'écrit en ligne (attribut style, pour un seul élément) ou en interne (balise <style> dans le <head>, pour toute la page). La syntaxe est toujours : sélecteur { propriété: valeur; }.

HTML
<head>
  <meta charset="UTF-8">
  <title>Club</title>
  <style>
    h1 {
      color: navy;
      text-align: center;
    }
  </style>
</head>
<body>
  <h1>Club informatique</h1>
  <p style="color: green;">Inscriptions ouvertes</p>
</body>
localhost/page.html
i

Sélecteurs utilisés en 2ème : le nom de l'élément (h1, p, table…). Les sélecteurs #id et .classe arrivent en 3ème.

Mettre en forme le texte

Annexe 2ème
CSS
<style>
  h2 {
    font-family: Georgia, serif;
    font-size: 26px;
    color: darkred;
  }
  p {
    font-weight: bold;
    font-style: italic;
    text-align: justify;
  }
</style>
localhost/page.html
★

La propriété abrégée font regroupe style, graisse, taille et police : font: italic bold 18px Arial;

Bordures

Annexe 2ème
CSS
<style>
  table {
    border-width: 2px;
    border-style: solid;
    border-color: navy;
  }
  td {
    border: 1px dashed gray;
  }
</style>
localhost/page.html

Arrière-plans

Annexe 2ème
CSS
<style>
  body {
    background-color: lightyellow;
  }
  h1 {
    background-image: url("motif.png");
    background-repeat: repeat-x;
  }
</style>
localhost/page.html
L'image de fond est remplacée ici par une couleur.

À retenir

  • CSS en ligne : attribut style ; CSS interne : <style> dans le head.
  • Syntaxe : sélecteur { propriété: valeur; }, chaque déclaration se termine par ;.
  • Gras et italique se font en CSS : font-weight, font-style.
  • Pas de fichier .css externe en 2ème année.

06

Limites du programme et progression

Ce qui ne s'enseigne pas en 2ème, et une répartition possible sur l'année.

À ne pas enseigner en 2ème année

  • Balises sémantiquesheader, nav, section, article, footer… (3ème)
  • JavaScriptintroduit en 3ème
  • CSS externefichier .css et balise link (3ème)
  • Types date, time, email, tel, password, range3ème
  • Sélecteurs #id, .classe, pseudo-classes3ème et 4ème
  • Mise en forme par balisesb, strong, i, em, u, font, center

Progression suggérée

Proposition

Fil rouge conseillé : un mini-site du lycée (accueil, emploi du temps, club, inscription) que l'élève enrichit à chaque séance.

TrimestreNotionsProduction de l'élève
1erSquelette, titres, paragraphes, listes, validation W3CPage d'accueil du lycée, validée
2èmeTableaux, liens, images, audio, vidéo, CSS en ligne et interneEmploi du temps + navigation entre pages
3èmeFormulaires, CSS des bordures et arrière-plansFiche d'inscription au club, mise en forme
