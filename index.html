Comment lire ce guide

Le code et son rendu

Chaque exemple montre le code à gauche et la page réellement affichée à droite. Les aperçus sont vivants : survolez, cliquez, saisissez.

La pastille de niveau

La pastille indique le niveau où la notion est introduite dans l'annexe : Annexe 2ème Annexe 3ème Annexe 4ème

À retenir

En fin de séquence : la synthèse, le tableau des propriétés CSS (valeurs de l'annexe, valeur utilisée, définition) et celui des méthodes.

Les interdits

Chaque niveau se termine par la liste de ce qui ne s'enseigne pas encore, avec l'alternative conforme.

Les règles qui reviennent à tous les niveaux

  • Aucune mise en forme par balise HTML : tout passe par le CSS.
  • Bouton de contrôle : input type="button" + onclick.
  • Unités CSS : px et % uniquement.
  • JavaScript : ch[i], substring, Math.trunc.
  • Erreur de saisie : alert() puis return.
  • SQL : jointures dans WHERE, date du jour DATE(NOW()).
  • PHP : mysqli procédural, connexion dans connexion.php.
  • Mots de passe comparés tels quels, sans hachage.
