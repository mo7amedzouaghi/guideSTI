🎯 À propos de ce guide

Ce guide présente de manière claire et structurée le curriculum officiel tunisien pour les classes de 2ème, 3ème et 4ème année STI. Chaque section contient des exemples de code, les attributs nécessaires et les paramètres des fonctions.

💾 Base de Données - Concepts

🛡️ Base de Données - Contraintes

🔍 SQL Simple - SELECT

-- Sélection simple SELECT nom, prenom, age FROM etudiants; -- Avec condition SELECT nom, prenom FROM etudiants WHERE age > 18; -- Avec tri SELECT nom, prenom FROM etudiants ORDER BY nom ASC; -- Sans doublons SELECT DISTINCT ville FROM etudiants;

➕ SQL Simple - INSERT, UPDATE, DELETE

-- INSERT INSERT INTO etudiants (nom, prenom, age) VALUES ('Ben Ali', 'Ahmed', 20); -- UPDATE UPDATE etudiants SET age = 21 WHERE nom = 'Ben Ali'; -- DELETE DELETE FROM etudiants WHERE age < 18;

🔧 SQL - Opérateurs

-- BETWEEN SELECT * FROM etudiants WHERE age BETWEEN 18 AND 25; -- LIKE SELECT * FROM etudiants WHERE nom LIKE 'Ben%'; -- IN SELECT * FROM etudiants WHERE ville IN ('Tunis', 'Sousse', 'Sfax'); -- IS NULL SELECT * FROM etudiants WHERE email IS NULL;
Comparaison: =, <>, >, <, >=, <= Logiques: AND, OR, NOT Spéciaux: BETWEEN, LIKE, IN, IS NULL

💾 BDD - Types de données

🏗️ SQL - Création de base

CREATE DATABASE ecole; DROP DATABASE ecole;

📋 SQL - Création de table

CREATE TABLE etudiants ( id INT PRIMARY KEY, nom VARCHAR(50) NOT NULL, prenom VARCHAR(50), age INT CHECK (age >= 0 AND age <= 150), email VARCHAR(100) UNIQUE, classe_id INT, FOREIGN KEY (classe_id) REFERENCES classes(id) ON DELETE CASCADE ON UPDATE CASCADE );

🔧 SQL - ALTER TABLE

-- Ajouter une colonne ALTER TABLE etudiants ADD telephone VARCHAR(20); -- Supprimer une colonne ALTER TABLE etudiants DROP telephone; -- Modifier le type (syntaxe annexe : ALTER TABLE t ALTER col type) -- Exécutable sous MySQL : ALTER TABLE etudiants CHANGE nom nom VARCHAR(100); -- Renommer une colonne (CHANGE : ancien nom, nouveau nom, type) ALTER TABLE etudiants CHANGE prenom first_name VARCHAR(100); -- Ajouter une contrainte ALTER TABLE etudiants ADD CONSTRAINT fk_classe FOREIGN KEY (classe_id) REFERENCES classes(id); -- Supprimer une contrainte ALTER TABLE etudiants DROP CONSTRAINT fk_classe;

🗑️ SQL - Suppression

DROP TABLE etudiants;

📊 SQL - Fonctions d'agrégation

SELECT ville, COUNT(*) AS nombre, AVG(age) AS age_moyen FROM etudiants GROUP BY ville HAVING COUNT(*) > 5;
COUNT() - Compter SUM() - Somme AVG() - Moyenne MIN() - Minimum MAX() - Maximum

🔗 SQL - Jointures (SQL-89)

Important : Utiliser la syntaxe classique avec WHERE
-- Jointure simple SELECT e.nom, e.prenom, c.nom AS classe FROM etudiants e, classes c WHERE e.classe_id = c.id; -- Jointure multiple SELECT e.nom, c.nom AS classe, n.nom AS niveau FROM etudiants e, classes c, niveaux n WHERE e.classe_id = c.id AND c.niveau_id = n.id;

🔍 SQL - Sous-requêtes

Uniquement non corrélées
SELECT nom, prenom FROM etudiants WHERE classe_id IN ( SELECT id FROM classes WHERE niveau = '3ème' );

📅 SQL - Fonctions date

-- Extraire des parties SELECT * FROM commandes WHERE YEAR(date_commande) = 2024 AND MONTH(date_commande) = 11; -- DATE() : Extraire date SELECT DATE('2024-11-19 14:30:45'); -- 2024-11-19 -- DAY(), MONTH(), YEAR() SELECT DAY('2024-11-19'); -- 19 SELECT MONTH('2024-11-19'); -- 11 SELECT YEAR('2024-11-19'); -- 2024 -- NOW() : Date et heure courantes SELECT NOW(); -- 2024-11-19 14:30:45 -- ADDDATE() : Ajouter des jours/intervalle SELECT ADDDATE('2024-11-19', 10); SELECT ADDDATE('2024-11-19', INTERVAL 1 MONTH); -- DATEDIFF() : Différence en jours SELECT DATEDIFF('2024-11-19', '2024-11-10'); -- 9 -- Date du jour : DATE(NOW()) (CURDATE() hors annexe) SELECT * FROM commandes WHERE date_commande = DATE(NOW());

🔗 PHP + MySQL - Connexion

Important : Utiliser uniquement mysqli (pas PDO)
<?php // connexion.php $conn = mysqli_connect('localhost', 'root', '', 'ecole') or die('Erreur de connexion au serveur'); ?>

🔍 PHP + MySQL - SELECT

<?php $sql = 'SELECT * FROM etudiants WHERE age > 18'; $result = mysqli_query($conn, $sql); if ($result) { while ($row = mysqli_fetch_array($result)) { echo $row['nom'] . ' ' . $row['prenom'] . '<br>'; // Ou : echo $row[0] . ' ' . $row[1] . '<br>'; } $nombre = mysqli_num_rows($result); echo 'Nombre de résultats: ' . $nombre; } else { echo 'Erreur: ' . mysqli_error($conn); } ?>

➕ PHP + MySQL - INSERT

<?php $nom = $_POST['nom']; $prenom = $_POST['prenom']; $age = $_POST['age']; $sql = "INSERT INTO etudiants (nom, prenom, age) VALUES ('$nom', '$prenom', $age)"; if (mysqli_query($conn, $sql)) { $affected = mysqli_affected_rows($conn); echo $affected . ' enregistrement inséré'; } else { echo 'Erreur: ' . mysqli_error($conn); } ?>

✏️ PHP + MySQL - UPDATE

<?php $id = $_GET['id']; $nouvelAge = $_POST['age']; $sql = "UPDATE etudiants SET age = $nouvelAge WHERE id = $id"; if (mysqli_query($conn, $sql)) { $affected = mysqli_affected_rows($conn); echo $affected . ' enregistrement(s) modifié(s)'; } ?>

🗑️ PHP + MySQL - DELETE

<?php $id = $_GET['id']; $sql = "DELETE FROM etudiants WHERE id = $id"; if (mysqli_query($conn, $sql)) { $affected = mysqli_affected_rows($conn); echo $affected . ' enregistrement(s) supprimé(s)'; } ?>

🔌 PHP + MySQL - Fermeture

<?php mysqli_close($conn); ?>

📚 Fonctions mysqli

mysqli_connect() - Connexion mysqli_query() - Exécuter requête mysqli_fetch_array() - Ligne (indices ou noms) mysqli_fetch_row() - Ligne (indices numériques) mysqli_num_rows() - Nombre de lignes mysqli_affected_rows() - Lignes affectées mysqli_error() - Message d'erreur mysqli_close() - Fermer connexion die() - Arrêter le script avec un message isset() - Tester l'existence d'une variable
