JavaScript avancé

Parcourir des groupes de boutons radio, modifier attributs et styles, piloter un média, préparer l'envoi vers PHP.

Script externe obligatoire

Annexe 4ème

En 4ème, tout le code JavaScript est dans un fichier .js relié par <script src>. Aucun script interne dans la page.

✗ Incorrect
HTML
<script>
  function verifier() { … }
</script>
✔ Conforme
HTML
<script src="js/controle.js"></script>

Groupe de boutons radio : getElementsByName

Annexe 4ème
JSjs/controle.js
function choixFiliere() {
  let options = document.getElementsByName("filiere");
  let choix = "";
  for (let i = 0; i < options.length; i++) {
    if (options[i].checked) {
      choix = options[i].value;
    }
  }
  if (choix == "") {
    alert("Choisissez une filière");
    return;
  }
  document.getElementById("res").innerHTML = "Filière : " + choix;
}

Contrôler avant l'envoi vers PHP

Annexe 4ème

Quand le formulaire part vers une page PHP, le contrôle se branche sur onsubmit de la balise form : la fonction renvoie false pour bloquer l'envoi, true pour l'autoriser.

HTMLinscription.html
<form action="inscription.php" method="post" onsubmit="return verifier()">
  <input type="text" id="nom" name="nom">
  <input type="submit" value="S'inscrire">
</form>
JSjs/controle.js
function verifier() {
  let nom = document.getElementById("nom").value;
  if (nom.length < 3) {
    alert("Nom trop court");
    return false;
  }
  return true;
}

À retenir

  • Script toujours externe en 4ème.
  • Groupe radio : getElementsByName + boucle sur checked.
  • Liste déroulante : tester selectedIndex.
  • onsubmit="return verifier()" pour un envoi vers PHP.

SQL : définition des données

Écrire soi-même la création de la base, des tables, des contraintes et leurs modifications.

Créer et supprimer une base

Annexe 4ème
SQL
CREATE DATABASE ecole;
DROP DATABASE ecole;

Créer une table avec ses contraintes

Annexe 4ème
SQL
CREATE TABLE Classe (
  idClasse VARCHAR(10) PRIMARY KEY,
  niveau   INT NOT NULL
);

CREATE TABLE Eleve (
  idEleve   INT,
  nom       VARCHAR(30) NOT NULL,
  prenom    VARCHAR(30) NOT NULL,
  dateNais  DATE,
  moyenne   DECIMAL(4,2) CHECK (moyenne BETWEEN 0 AND 20),
  ville     VARCHAR(30) DEFAULT 'Manouba',
  email     VARCHAR(60) UNIQUE,
  idClasse  VARCHAR(10),
  CONSTRAINT pk_eleve PRIMARY KEY (idEleve),
  CONSTRAINT fk_eleve_classe FOREIGN KEY (idClasse)
    REFERENCES Classe(idClasse)
    ON UPDATE CASCADE
    ON DELETE CASCADE
);
!

AUTO_INCREMENT n'est pas dans l'annexe : la clé primaire est saisie explicitement.

Modifier la structure : ALTER TABLE

Annexe 4ème
SQL
-- Ajouter une colonne
ALTER TABLE Eleve ADD tel VARCHAR(8);

-- Supprimer une colonne
ALTER TABLE Eleve DROP tel;

-- Renommer une colonne / changer son type (MySQL)
ALTER TABLE Eleve CHANGE prenom prenomEleve VARCHAR(40);

-- Ajouter / supprimer une contrainte
ALTER TABLE Eleve ADD CONSTRAINT uq_nom UNIQUE (nom, prenomEleve);
ALTER TABLE Eleve DROP CONSTRAINT uq_nom;

-- Supprimer une table
DROP TABLE Eleve;
i

L'annexe mentionne aussi ALTER TABLE t ALTER colonne type et ALTER TABLE t RENAME nom1 TO nom2. Sous MySQL, ces formes ne s'exécutent pas pour modifier une colonne : on enseigne CHANGE (ancien nom, nouveau nom, type).

À retenir

  • Clé primaire et clé étrangère se déclarent avec CONSTRAINT nom.
  • ON DELETE / ON UPDATE CASCADE propage les suppressions et modifications.
  • Renommer ou retyper une colonne : CHANGE.
  • Pas d'AUTO_INCREMENT.

SQL : interrogation avancée

Calculer des statistiques, regrouper, relier plusieurs tables et imbriquer des requêtes.

Fonctions d'agrégation, GROUP BY et HAVING

Annexe 4ème
SQL
-- Statistiques globales
SELECT COUNT(*) AS nbEleves, AVG(moyenne) AS moyClasse,
       MIN(moyenne), MAX(moyenne)
FROM Eleve;

-- Par groupe
SELECT idClasse, COUNT(*) AS effectif
FROM Eleve
GROUP BY idClasse
HAVING COUNT(*) > 25
ORDER BY effectif DESC;
★

WHERE filtre les lignes avant le regroupement, HAVING filtre les groupes après.

Jointures (syntaxe classique)

Annexe 4ème

Les tables sont listées dans FROM, la condition de jointure s'écrit dans WHERE. Pas de mot-clé JOIN.

SQL
SELECT E.nom, E.prenom, C.niveau
FROM Eleve E, Classe C
WHERE E.idClasse = C.idClasse
  AND C.niveau = 4;

-- Trois tables
SELECT L.titre, E.nom, P.dateEmprunt
FROM Livre L, Eleve E, Emprunt P
WHERE P.idLivre = L.idLivre
  AND P.idEleve = E.idEleve;

Sous-requêtes non corrélées

Annexe 4ème
SQL
-- Élèves dont la moyenne dépasse la moyenne générale
SELECT nom, moyenne
FROM Eleve
WHERE moyenne > (SELECT AVG(moyenne) FROM Eleve);

-- Livres jamais empruntés
SELECT titre FROM Livre
WHERE idLivre NOT IN (SELECT idLivre FROM Emprunt);
!

La sous-requête doit pouvoir s'exécuter seule : les sous-requêtes corrélées (qui utilisent une colonne de la requête principale) sont hors programme.

Fonctions sur les dates

Annexe 4ème
SQL
SELECT nom, YEAR(dateNais) FROM Eleve;
SELECT * FROM Emprunt WHERE MONTH(dateEmprunt) = 10;
SELECT DAY(NOW());
SELECT * FROM Emprunt WHERE dateEmprunt = DATE(NOW());          -- aujourd'hui
SELECT idLivre, ADDDATE(dateEmprunt, 15) AS retourPrevu FROM Emprunt;
SELECT idLivre, DATEDIFF(DATE(NOW()), dateEmprunt) AS jours FROM Emprunt;
!

CURDATE() n'est pas dans l'annexe : la date du jour s'écrit DATE(NOW()).

À retenir

  • Ordre des clauses : SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY.
  • Jointure : tables dans FROM, condition dans WHERE.
  • Sous-requête non corrélée seulement.
  • Date du jour : DATE(NOW()).

Cycle mysqli : connexion, requête, fermeture

Annexe 4ème

La connexion est écrite une fois dans connexion.php, puis importée par require dans chaque page.

PHPconnexion.php
<?php
  $cnx = mysqli_connect("localhost", "root", "", "ecole")
         or die("Connexion impossible");
?>
PHPliste.php
<?php
  require("connexion.php");

  $req = "SELECT nom, prenom, moyenne FROM Eleve ORDER BY moyenne DESC";
  $res = mysqli_query($cnx, $req) or die(mysqli_error($cnx));

  echo "<p>" . mysqli_num_rows($res) . " élève(s)</p>";
  echo "<table border='1'>";
  while ($ligne = mysqli_fetch_array($res)) {
    echo "<tr><td>" . $ligne["nom"] . "</td><td>" . $ligne["prenom"]
       . "</td><td>" . $ligne["moyenne"] . "</td></tr>";
  }
  echo "</table>";

  mysqli_close($cnx);
?>

Authentification

Annexe 4ème

Le mot de passe saisi est comparé tel quel à celui de la base, sans hachage. On vérifie qu'exactement une ligne correspond.

PHPconnexion_utilisateur.php
<?php
  require("connexion.php");

  $login = $_POST["login"];
  $mdp = $_POST["mdp"];

  $req = "SELECT nom FROM Utilisateur WHERE login = '$login' AND mdp = '$mdp'";
  $res = mysqli_query($cnx, $req) or die(mysqli_error($cnx));

  if (mysqli_num_rows($res) == 1) {
    $ligne = mysqli_fetch_row($res);
    echo "Bienvenue " . $ligne[0];
  } else {
    echo "Login ou mot de passe incorrect";
  }
  mysqli_close($cnx);
?>

À retenir

  • mysqli procédural uniquement : jamais PDO ni new mysqli().
  • Connexion centralisée dans connexion.php, importée par require.
  • Toujours tester isset() avant de lire $_POST.
  • Mot de passe comparé tel quel, sans hachage.

Limites du programme et progression

Ce qui ne s'enseigne pas en 4ème, et une organisation possible vers l'épreuve pratique du bac.

À ne pas enseigner en 4ème année

  • PDO, new mysqli(), requêtes préparéesmysqli procédural uniquement
  • Sessions et cookies
  • switch et var_dump() en PHP
  • Hachage des mots de passemd5, password_hash…
  • AUTO_INCREMENT, CURDATE()DATE(NOW())
  • JOIN explicitesyntaxe classique avec WHERE
  • Sous-requêtes corrélées
  • Attribut pattern, console.log()
  • Script JavaScript internefichier .js externe obligatoire
  • Upload de fichiers, AJAX, JSON
