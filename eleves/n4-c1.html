Liste de suggestions : datalist

Annexe 4ème

<datalist> propose des valeurs pendant la saisie, tout en laissant l'utilisateur taper autre chose. Il est relié au champ par l'attribut list.

HTML
<label for="ville">Ville :</label>
<input type="text" id="ville" name="ville" list="villes">
<datalist id="villes">
  <option value="Tunis">
  <option value="Sousse">
  <option value="Sfax">
</datalist>

Pseudo-classes et sélecteurs avancés

Annexe 4ème
CSS
a:link    { color: #1D4ED8; }  /* non visité   */
a:visited { color: #5B2C9F; }  /* visité       */
a:hover   { color: #D35400; }  /* survolé      */
a:active  { color: #C62828; }  /* au clic      */
input:focus { border: 2px solid #F5B800; }

input[required]     { border-left: 4px solid red; }
input[type="email"] { width: 250px; }
p.note              { color: gray; }
