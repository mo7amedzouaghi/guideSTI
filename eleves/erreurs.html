HTML5

Les erreurs de structure les plus courantes dans les copies et les TP.

Mettre en forme avec des balises

Tous niveaux
✗ Incorrect
HTML
<p><b>Attention</b> : <i>date limite</i></p>
✔ Conforme
HTML
<p><span class="alerte">Attention</span> : <span class="date">date limite</span></p>

/* style.css */
.alerte { font-weight: bold; }
.date { font-style: italic; }

Le gras et l'italique relèvent du CSS (font-weight, font-style). Les balises de mise en forme ne sont pas dans l'annexe.

Utiliser <button> pour un contrôle JavaScript

3ème et 4ème
✗ Incorrect
HTML
<button onclick="verifier()">Valider</button>
✔ Conforme
HTML
<input type="button" value="Valider" onclick="verifier()">

La balise <button> n'est pas dans l'annexe : le bouton est un input de type button.

Oublier l'attribut alt ou fermer mal les balises

Tous niveaux
✗ Incorrect
HTML
<img src="carthage.jpg">
<p>Carthage<p>Dougga
✔ Conforme
HTML
<img src="carthage.jpg" alt="Ruines de Carthage">
<p>Carthage</p>
<p>Dougga</p>

Deux erreurs signalées par le validateur W3C.

Boutons radio sans name commun

2ème
✗ Incorrect
HTML
<input type="radio" name="g1" value="F"> Fille
<input type="radio" name="g2" value="G"> Garçon
✔ Conforme
HTML
<input type="radio" name="genre" value="F"> Fille
<input type="radio" name="genre" value="G"> Garçon

Avec deux name différents, les deux options peuvent être cochées en même temps.

CSS3

Mise en page et effets : ce qui fonctionne mais sort de l'annexe, et ce qui ne fonctionne pas du tout.

Déclarer la transition sur :hover

3ème
✗ Incorrect
CSS
.menu a:hover {
  background-color: gold;
  transition: background-color 1s;
}
✔ Conforme
CSS
.menu a {
  transition: background-color 1s;
}
.menu a:hover {
  background-color: gold;
}

Sur :hover, la transition ne joue qu'à l'aller : le retour est brutal. Elle se déclare sur l'élément.

Écrire plusieurs fois transform

3ème
✗ Incorrect
CSS
.logo:hover {
  transform: rotate(10deg);
  transform: scale(1.2);
}
✔ Conforme
CSS
.logo:hover {
  transform: rotate(10deg) scale(1.2);
}

La seconde déclaration écrase la première : seule la mise à l'échelle s'applique.

Animer left sans positionner l'élément

3ème
✗ Incorrect
CSS
.bus {
  animation: rouler 4s infinite;
}
✔ Conforme
CSS
.bus {
  position: relative;
  animation: rouler 4s infinite;
}

left et top sont sans effet sur un élément non positionné.

Utiliser Flexbox ou des unités hors programme

3ème et 4ème
✗ Incorrect
CSS
.conteneur {
  display: flex;
  height: 100vh;
  font-size: 1.2em;
}
✔ Conforme
CSS
html, body { height: 100%; }
.gauche { float: left; width: 30%; height: 100%; }
.droite { float: right; width: 68%; height: 100%; }
.conteneur { font-size: 18px; }

Mise en page par float et position ; unités px et % uniquement.

JavaScript

Les écarts à l'annexe qui coûtent des points à l'épreuve pratique.

charAt, substr et Math.floor

3ème et 4ème
✗ Incorrect
JS
let c = ch.charAt(0);
let debut = ch.substr(0, 3);
let n = Math.floor(Math.random() * 6) + 1;
✔ Conforme
JS
let c = ch[0];
let debut = ch.substring(0, 3);
let n = Math.trunc(Math.random() * 6) + 1;

Seules ch[i], substring et Math.trunc figurent dans l'annexe.

Continuer après une erreur

3ème et 4ème
✗ Incorrect
JS
if (nom == "") {
  alert("Nom obligatoire");
}
document.getElementById("msg").innerHTML = "Inscrit";
✔ Conforme
JS
if (nom == "") {
  alert("Nom obligatoire");
  return;
}
document.getElementById("msg").innerHTML = "Inscrit";

Sans return, le message de succès s'affiche même quand la saisie est fausse.

Tester « chiffres uniquement » avec isNaN

3ème et 4ème
✗ Incorrect
JS
if (isNaN(tel) || tel.length != 8) {
  alert("Téléphone invalide");
  return;
}
✔ Conforme
JS
if (tel.length != 8 || !estChiffres(tel)) {
  alert("Téléphone invalide");
  return;
}

isNaN("1.5e3") et isNaN(" 12") renvoient false : des points, des espaces ou un exposant passent le test. Parcourir la chaîne avec ch[i].

Afficher le mois avec getMonth()

3ème
✗ Incorrect
JS
let d = new Date();
alert(d.getDate() + "/" + d.getMonth() + "/" + d.getFullYear());
✔ Conforme
JS
let d = new Date();
alert(d.getDate() + "/" + (d.getMonth() + 1) + "/" + d.getFullYear());

getMonth() renvoie 0 pour janvier. Les parenthèses évitent une concaténation « 9 » + « 1 » = « 91 ».

Additionner des valeurs de champs

3ème
✗ Incorrect
JS
let total = document.getElementById("a").value + document.getElementById("b").value;
✔ Conforme
JS
let total = Number(document.getElementById("a").value) + Number(document.getElementById("b").value);

value est toujours une chaîne : « 12 » + « 8 » donne « 128 ».

Écrire readonly en JavaScript

4ème
✗ Incorrect
JS
document.getElementById("cin").readonly = true;
✔ Conforme
JS
document.getElementById("cin").readOnly = true;

La propriété JavaScript s'écrit avec un O majuscule ; l'attribut HTML reste readonly.

SQL

Syntaxe classique des jointures et fonctions de l'annexe.

Jointure avec JOIN

4ème
✗ Incorrect
SQL
SELECT E.nom, C.niveau
FROM Eleve E JOIN Classe C ON E.idClasse = C.idClasse;
✔ Conforme
SQL
SELECT E.nom, C.niveau
FROM Eleve E, Classe C
WHERE E.idClasse = C.idClasse;

La jointure s'écrit dans WHERE.

Filtrer un agrégat avec WHERE

4ème
✗ Incorrect
SQL
SELECT idClasse, COUNT(*) FROM Eleve
WHERE COUNT(*) > 25
GROUP BY idClasse;
✔ Conforme
SQL
SELECT idClasse, COUNT(*) FROM Eleve
GROUP BY idClasse
HAVING COUNT(*) > 25;

Une condition sur un groupe va dans HAVING.

CURDATE et AUTO_INCREMENT

4ème
✗ Incorrect
SQL
CREATE TABLE Emprunt (id INT PRIMARY KEY AUTO_INCREMENT, d DATE);
SELECT * FROM Emprunt WHERE d = CURDATE();
✔ Conforme
SQL
CREATE TABLE Emprunt (id INT PRIMARY KEY, d DATE);
SELECT * FROM Emprunt WHERE d = DATE(NOW());

Ni AUTO_INCREMENT ni CURDATE() ne sont dans l'annexe.

Renommer une colonne

4ème
✗ Incorrect
SQL
ALTER TABLE Eleve RENAME COLUMN prenom TO prenomEleve;
✔ Conforme
SQL
ALTER TABLE Eleve CHANGE prenom prenomEleve VARCHAR(30);

CHANGE : ancien nom, nouveau nom, type.

PHP

mysqli procédural, une connexion centralisée, aucun hachage.

PDO ou mysqli orienté objet

4ème
✗ Incorrect
PHP
$cnx = new PDO("mysql:host=localhost;dbname=ecole", "root", "");
$cnx = new mysqli("localhost", "root", "", "ecole");
✔ Conforme
PHP
$cnx = mysqli_connect("localhost", "root", "", "ecole")
       or die("Connexion impossible");

Seules les fonctions mysqli_* procédurales sont au programme.

Lire $_POST sans tester isset

4ème
✗ Incorrect
PHP
$nom = $_POST["nom"];
echo "Bonjour " . $nom;
✔ Conforme
PHP
if (isset($_POST["nom"])) {
  $nom = $_POST["nom"];
  echo "Bonjour " . $nom;
}

Sans isset, l'ouverture directe de la page provoque un avertissement.

Hacher le mot de passe

4ème
✗ Incorrect
PHP
$mdp = md5($_POST["mdp"]);
✔ Conforme
PHP
$mdp = $_POST["mdp"];

Le mot de passe est comparé tel quel à celui de la base : aucune fonction de hachage dans les supports.

Utiliser switch

4ème
✗ Incorrect
PHP
switch ($mention) {
  case "TB": echo "Très bien"; break;
}
✔ Conforme
PHP
if ($mention == "TB") {
  echo "Très bien";
} else if ($mention == "B") {
  echo "Bien";
}

switch n'est pas au programme de PHP.
