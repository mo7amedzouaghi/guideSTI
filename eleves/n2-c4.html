La balise form et les champs de base

Annexe 2ème

Le formulaire regroupe les champs. <label for="…"> relie un texte à un champ via son id : cliquer sur le texte active le champ. <fieldset> et <legend> regroupent visuellement des champs liés.

HTMLinscription.html
<form action="inscription.php" method="post">
  <fieldset>
    <legend>Inscription au club</legend>
    <label for="nom">Nom :</label>
    <input type="text" id="nom" name="nom"><br>

    <label for="age">Âge :</label>
    <input type="number" id="age" name="age"><br>

    Classe :
    <input type="radio" name="classe" value="2A"> 2A
    <input type="radio" name="classe" value="2B"> 2B<br>

    <input type="checkbox" name="photo" value="oui">
    J'accepte d'être photographié(e)<br>

    <input type="submit" value="Envoyer">
    <input type="reset" value="Effacer">
  </fieldset>
</form>
localhost/inscription.html
!

Les boutons radio d'un même groupe portent le même name : c'est ce qui rend le choix exclusif.

Listes déroulantes et zones de texte

Annexe 2ème

<select> propose une liste de <option> ; selected présélectionne une option et multiple autorise plusieurs choix. <textarea> accepte un texte sur plusieurs lignes.

HTML
<label for="gouv">Gouvernorat :</label>
<select id="gouv" name="gouv">
  <option value="">-- Choisir --</option>
  <option value="Manouba" selected>Manouba</option>
  <option value="Tunis">Tunis</option>
</select>
<br>
<label for="msg">Message :</label><br>
<textarea id="msg" name="msg" rows="3" cols="30"
  maxlength="200" placeholder="Votre message"></textarea>
localhost/page.html

3 Je retiens

À retenir

  • method vaut get ou post ; action désigne la page de traitement.
  • name identifie la donnée envoyée, id sert au label.
  • Radio : même name pour un choix unique.
  • En 2ème : text, number, radio, checkbox, submit, reset uniquement.

Balises et types de la séquence

BaliseAttributs (annexe)DéfinitionUtilité
<form>action, method, targetFormulaire.Regrouper des champs et envoyer leurs valeurs à une page de traitement.
<fieldset>—Groupe de champs.Encadrer des champs liés (identité, coordonnées).
<legend>—Titre d'un fieldset.Nommer le groupe de champs.
<label>forÉtiquette d'un champ.Décrire le champ ; un clic sur l'étiquette active le champ dont l'id est for.
<input>type, name, valueChamp de saisie (text, number, radio, checkbox, submit, reset).Recueillir une donnée ou déclencher l'envoi / la remise à zéro.
<select>name, required, disabled, multipleListe déroulante.Proposer un choix parmi plusieurs options sans encombrer la page.
<option>value, selectedChoix d'une liste.Définir chaque valeur proposée par le select.
<textarea>name, rows, cols, maxlength, placeholderZone de texte multiligne.Saisir un texte long (message, commentaire).
