Transition et transformation

Faire passer un élément d'un état à un autre en douceur, au survol de la souris.

🎬 La notion en animation

L'illustration se lit toute seule : ⏸ / ▶ pour la commander, ↻ pour la rejouer.

Une transition, image par imagetransition: all 1s
état initial :hover détecté transform: scale(1.3) background-color
.carte
Étape 1 : la carte est dans son état initial.
Sans transition, le changement est instantané. Avec transition, le navigateur calcule les états intermédiaires pendant la durée choisie.

✎ Exemple d'application

Sans animation : pour modifier les valeurs vous-même, passez à « Mettre en pratique ».

✍ Au survol d'une carte, l'agrandir, la tourner de 5° et changer sa couleur de fond en 1 seconde.
HTML 
<div class="carte">Survolez-moi</div>
CSS 
.carte {  width: 180px;  padding: 16px;  background-color: teal;  transition: all 1s;}.carte:hover {  transform: scale(1.15) rotate(5deg);  background-color: orangered;}
Résultat :
Survolez-moi

⚠ Pièges fréquents

Placer transition dans :hover seulement : l'effet est fluide à l'aller mais brutal au retour.
Oublier l'unité de durée : transition: all 1 est ignoré, il faut 1s ou 1000ms.
Écrire deux transform séparés : le second écrase le premier. On les enchaîne dans une seule déclaration.
Mettre une virgule entre les fonctions : scale(1.2), rotate(5deg) est invalide, on sépare par un espace.

📌 À retenir

La transition se déclare sur l'état normal de l'élément.
La pseudo-classe :hover définit l'état d'arrivée.
transform ne déplace pas les autres éléments de la page.
Plusieurs transformations s'écrivent dans une seule propriété transform.
