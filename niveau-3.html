01

HTML5 avancé

Relier des fichiers externes, structurer la page avec les balises sémantiques et enrichir les formulaires.

Relier une feuille de style et un script

Annexe 3ème

À partir de la 3ème, le CSS et le JavaScript vivent dans des fichiers séparés, reliés dans le <head>. Une même feuille de style sert alors à toutes les pages du site.

HTMLindex.html
<head>
  <meta charset="UTF-8">
  <title>Découvrir la Tunisie</title>
  <link rel="stylesheet" type="text/css" href="css/style.css">
  <script type="text/javascript" src="js/controle.js"></script>
</head>
BaliseAttributs (annexe)Rôle
<link>href, rel, typeRelie une ressource externe (feuille de style)
<script>src, typeRelie (ou contient) un script JavaScript
<style>type, mediaFeuille de style interne

Les balises de structuration sémantique

Annexe 3ème

Les balises sémantiques remplacent les <div> anonymes par des zones qui ont un sens. La page devient lisible comme un plan, par l'élève comme par les moteurs de recherche.

HTML

  <nav>Accueil | Régions | Contact</nav>
  <main>
    <section>
      <article>Carthage</article>
      <article>Dougga</article>
    </section>
    <aside>Le saviez-vous ?</aside>
  </main>
  <footer>
    <address>Lycée Oued Ellil</address>
  </footer>
</body>

Conteneurs, iframe, figure et details

Annexe 3ème

<div> (bloc) et <span> (en ligne) sont des conteneurs neutres, utiles pour appliquer un style. <iframe> affiche une autre page à l'intérieur de la page ; nommé par name, il peut servir de cible à un lien. <figure> associe une illustration à sa légende <figcaption>, et <details> / <summary> créent un bloc dépliable.

HTML
<a href="carthage.html" target="cadre">Carthage</a>
<iframe src="accueil.html" name="cadre"
        width="300" height="80"></iframe>

<figure>
  <img src="dougga.jpg" alt="Théâtre de Dougga">
  <figcaption>Le théâtre romain de Dougga</figcaption>
</figure>

<details>
  <summary>Horaires de visite</summary>
  Tous les jours de 8h à 17h.
</details>

Cliquez sur « Horaires de visite » pour déplier.

Formulaires : nouveaux types et attributs

Annexe 3ème

  <input type="time">

  <input type="text" value="Oued Ellil" readonly>
  <input type="button" value="Valider" onclick="verifier()">
</form>

Événements HTML

Annexe 3ème

Un événement relie une action de l'utilisateur à une fonction JavaScript, directement dans la balise. En 3ème, on n'utilise pas addEventListener.

ÉvénementSe déclenche quand…Exemple
onclickon clique sur l'élément<input type="button" onclick="calculer()">
oninputla valeur change à chaque modification<input type="range" oninput="afficher()">
onchangela valeur change et le champ est quitté<input type="date" onchange="age()">
onfocusle champ reçoit le focus<input onfocus="aide()">
onblurle champ perd le focus<input onblur="verifierNom()">
onloadla page a fini de charger<body onload="init()">

À retenir

  • CSS et JS sont dans des fichiers externes reliés par link et script.
  • Balises sémantiques : header, nav, main, section, article, aside, footer.
  • Un iframe nommé (name) devient la cible d'un lien (target).
  • Bouton de contrôle : <input type="button" onclick="…">, jamais <button>.

Mise en page : boîtes et positionnement

Dimensionner les blocs, les faire flotter et les positionner (float, position, display), sans Grid.

Le modèle de boîte

Annexe 3ème

Chaque élément est une boîte : le contenu (width, height), la marge intérieure (padding), la bordure, puis la marge extérieure (margin).

CSS
.carte {
  width: 220px;
  padding: 15px;
  border: 3px solid #1D4ED8;
  margin: 20px;
  border-radius: 10px;
  box-shadow: 4px 4px 8px gray;
}

display, float et position

Annexe 3ème

La mise en page de 3ème repose sur float (blocs côte à côte) et position. Pour une page pleine hauteur : html, body { height: 100%; } puis des hauteurs en % sur les enfants.

  float: left;
  width: 25%;
}
section {
  float: right;
  width: 70%;
}
footer {
  clear: both;
}
.badge {
  position: absolute;
  top: 10px;

Effets : transitions, transformations, animations

Donner du mouvement à la page : passer en douceur d'un état à un autre, déformer, animer.

Transitions

Annexe 3ème

Une transition rend progressif le changement d'une propriété. Elle se déclare sur l'élément lui-même ; le changement est provoqué par :hover.

CSS
.carre {
  width: 100px;
  background-color: lightblue;
  transition: width 2s 0.5s;
}
.carre:hover {
  width: 200px;
}
localhost/page.html
Survolez le carré : sa largeur passe à 200px en 2s, après 0,5s.
!

transition se place sur l'élément, jamais sur :hover. transition-timing-function (ease, linear…) n'est pas dans l'annexe.

Transformations

Annexe 3ème

transform fait tourner, agrandir, déplacer ou incliner un élément. Toutes les fonctions s'écrivent sur une seule ligne, sinon seule la dernière s'applique.

CSS
.logo {
  transition: transform 1s;
}
.logo:hover {
  transform: rotate(15deg) scale(1.3) translate(20px, 0px);
}
localhost/page.html
Survolez le logo.
FonctionEffetExemple
rotate()Rotationrotate(45deg)
scale()Agrandissement / réductionscale(1.5)
translate()Déplacement (x, y)translate(50px, 20px)
skew()Inclinaisonskew(10deg, 5deg)

Animations

Annexe 3ème

Une animation enchaîne des états définis dans @keyframes, sans action de l'utilisateur. Pour animer left ou top, l'élément doit être positionné.

CSS
@keyframes traversee {
  0%   { left: 0px; }
  100% { left: 220px; }
}
.bateau {
  position: relative;
  animation-name: traversee;
  animation-duration: 3s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}
localhost/page.html

À retenir

  • Transition = changement progressif déclenché par un événement (:hover).
  • Animation = enchaînement automatique d'états définis par @keyframes.
  • transform : toutes les fonctions sur une seule ligne.
  • translate(x, y) uniquement (pas translateX / translateY).

Chaînes de caractères

Annexe 3ème

On accède à un caractère par son indice : ch[i] (le premier est ch[0]). Les méthodes ci-dessous sont les seules de l'annexe.

JS
let ch = "Oued Ellil";
ch.length;               // 10
ch[0];                   // "O"   (jamais charAt)
ch.indexOf("E");         // 5
ch.lastIndexOf("l");     // 9
ch.substring(0, 4);      // "Oued" (jamais substr)
ch.replace("Oued", "Wed");
ch.toUpperCase();        // "OUED ELLIL"
ch.toLowerCase();
"  ok  ".trim();          // "ok"
String.fromCharCode(65); // "A"
✎

Fonction type à faire construire : tester qu'une chaîne ne contient que des chiffres (téléphone, code postal, CAPTCHA).

JS
function estChiffres(ch) {
  if (ch.length == 0) {
    return false;              // chaîne vide refusée
  }
  for (let i = 0; i < ch.length; i++) {
    if (ch[i] < "0" || ch[i] > "9") {
      return false;
    }
  }
  return true;
}

Contrôler un formulaire

Annexe 3ème

Schéma attendu à l'examen : un bouton type="button" appelle verifier() ; chaque erreur affiche un alert() puis return ; si tout est correct, le message de succès s'écrit avec innerHTML.

JSjs/controle.js
function verifier() {
  let nom = document.getElementById("nom").value;
  let tel = document.getElementById("tel").value;

  if (nom.length < 3) {
    alert("Le nom doit contenir au moins 3 lettres");
    return;
  }
  if (tel.length != 8 || !estChiffres(tel)) {
    alert("Le téléphone doit contenir 8 chiffres");
    return;
  }
  document.getElementById("msg").innerHTML =
    "Inscription enregistrée pour " + nom;
}
localhost/inscription.html
Le numéro n'a que 7 chiffres : cliquez sur Valider, corrigez, recommencez.

À retenir

  • Lire : getElementById(id).value ; écrire : innerHTML.
  • Bouton : input type="button" + onclick.
  • Erreur : alert() puis return.
  • Caractère : ch[i] ; extraction : substring.
  • Arrondis : Math.trunc et Math.round seulement.
  • Mois affiché : getMonth() + 1.

Créer la base en mode assisté (phpMyAdmin)

Annexe 3ème

En 3ème, la base et ses tables se créent avec l'interface graphique : aucune instruction CREATE, ALTER ou DROP n'est écrite à la main.

  1. Démarrer XAMPP

    Lancer Apache et MySQL, puis ouvrir localhost/phpmyadmin.

  2. Créer la base

    Onglet Bases de données : saisir bibliotheque, interclassement utf8mb4_general_ci.

  3. Créer chaque table

    Nom, nombre de colonnes, puis pour chaque champ : nom, type, taille, Null ou non, index PRIMARY.

  4. Relier les tables

    Onglet Structure → Vue relationnelle : choisir la table et le champ référencés (moteur InnoDB).

  5. Saisir des données

    Onglet Insérer, puis vérifier dans Parcourir.

Interroger une table en SQL

Annexe 3ème
SQL
-- Sélection, condition, tri
SELECT titre, annee FROM Livre
WHERE annee >= 2000
ORDER BY annee DESC;

-- Sans doublons
SELECT DISTINCT nationalite FROM Auteur;

-- Opérateurs
SELECT * FROM Livre WHERE annee BETWEEN 1990 AND 2010;
SELECT * FROM Livre WHERE titre LIKE 'Le%';
SELECT * FROM Eleve WHERE classe IN ('3SI1', '3SI2');
SELECT * FROM Livre WHERE idAuteur IS NULL;

-- Mise à jour des données
INSERT INTO Eleve (idEleve, nom, prenom, classe)
VALUES (25, 'Ben Salah', 'Rim', '3SI1');

UPDATE Eleve SET classe = '3SI2' WHERE idEleve = 25;

DELETE FROM Eleve WHERE idEleve = 25;

En 3ème : une seule table par requête. Jointures, fonctions d'agrégation, GROUP BY et sous-requêtes sont réservés à la 4ème.
